Eval

Évaluation des formations PSE1, PSE2, PIC F, PAE FPSE et Chef d’équipe · fonctionne sans réseau

AndroidInstaller l'application

Télécharger l'application (APK, 9 Mo)
  1. Touchez le bouton ci-dessus, puis ouvrez le fichier téléchargé.
  2. Si Android le demande, autorisez « Installer des applis inconnues » pour Chrome (ou Fichiers).
  3. Touchez « Installer » : l'application Eval apparaît avec les autres applis.

Avec l'APK, le partage des PDF passe par le menu Android : mail, Bluetooth, Quick Share, Drive, WhatsApp…

iPhone / iPadAjouter à l'écran d'accueil

Ouvrir l'application
  1. Ouvrez cette page dans Safari, puis touchez « Ouvrir l'application ».
  2. Touchez le bouton Partager ⎙, puis « Sur l'écran d'accueil ».
  3. Lancez « Eval » depuis l'écran d'accueil une première fois avec du réseau : ensuite, elle fonctionne hors ligne.

Sans installation

Utiliser dans le navigateur

Sur Android, Chrome propose aussi « Installer l'application » depuis son menu ⋮.

Les données (formations, fiches, résultats) restent sur l'appareil. Pensez à envoyer régulièrement une sauvegarde depuis Réglages.
